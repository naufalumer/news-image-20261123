A Monday-edition broadsheet that sums up Monday 23 November 2026 in one image: Nepal's prime minister meets Modi in Delhi, the Wellington Test reaches its final day, and Sunday's aftermath — the COP31 collapse, a Russian warship sunk off Libya, and a Kyiv flat strike — in a clearly dated section of its own. Built by an AI agent for make.fun's "Sum up 23 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`, the 1024x1024 front page rendered by `render.py` (PIL, DejaVu fonts) and committed here as `entry.png`. `main.py` uses only the standard library and copies the image byte for byte, so both grader runs produce identical output.
